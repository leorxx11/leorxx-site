        令牌
        MCP

        带令牌的 MCP 地址给只能填地址的客户端用，它就等于令牌，别外传。

        怎么用 
        curl -H "authorization: Bearer 令牌" -H "x-filename: photo.jpg" --data-binary @photo.jpg /api/v1/upload

        请求头带 Authorization: Bearer 令牌。通过接口或 MCP 上传的文件也会自动摆上你的桌面：
        「上传」权限对应 POST /api/v1/upload，请求体是文件原始字节；
        「读取」权限对应 GET /api/v1/files?q=关键词&kind=text，列出或搜索文件；
        「MCP」地址填 /api/mcp，读取权限给 list_files、read_file，上传权限给 upload_file。令牌都不能删除文件。
